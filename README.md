# Steel Life — prenotazione sala pesi

Sito separato per la sala pesi, con disponibilità condivise tra i dispositivi tramite il database Cloudflare D1 usato dal sito dei corsi.

- Capienza sala pesi: 6 persone per fascia.
- Orari: lunedì-venerdì 07:00-21:00; sabato 07:00-13:00.
- Prenotazioni della sala pesi salvate con attività `Sala Pesi`, separate da MMA, Boxe, Kickboxing e BJJ.
- Si possono prenotare le fasce future della settimana selezionata.
- Ogni prenotazione o disdetta riuscita aggiorna il conteggio online prima di aprire WhatsApp.
